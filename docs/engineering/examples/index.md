# Ejemplos de Referencia

Estos ejemplos muestran como aplicar la filosofia del manual en proyectos nuevos.

No son una aplicacion completa. Son patrones pequenos y copiables que indican donde debe vivir cada pieza y que responsabilidades debe tener.

## Como Usarlos

Antes de implementar una feature real:

1. Lee el ejemplo mas parecido.
2. Copia la estructura, no necesariamente el codigo literal.
3. Cambia nombres y campos al dominio real.
4. Comprueba que la feature atraviesa todas las capas necesarias.
5. Actualiza documentacion si introduces una decision nueva.

## Dominio de Ejemplo

Los ejemplos usan un dominio generico de CRM deportivo:

* `clubs`
* `players`
* `teams`
* `seasons`

El dominio es solo un soporte. La estructura sirve para cualquier aplicacion.
